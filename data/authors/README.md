# data/authors/ — expansion-author snapshots

One directory per **public-domain** expansion author (docs/EXPANSION.md Tier 2), snapshotted
from its working `WLM_ROOT` tree by `scripts/snapshot_author.py`. Committed for the same
reason the Chesterton fixture is: this is a research repository first, and a result is only
verifiable against the exact corpus and pairs that produced it.

| Path | What | Why committed |
|---|---|---|
| `<name>/author/**` | the author corpus, verbatim | pins the exact text behind every number |
| `<name>/distractor/**` | the verifier's negative class | the AUC is meaningless without it |
| `<name>/pairs.jsonl` | API-generated (question, passage) pairs | non-deterministic API calls — cannot be regenerated identically |
| `../../runs/authors/<name>/**` | run records (report.json, gen.jsonl, …) | the science; allow-listed by the global run-record rules |

The pipeline never reads from here — runs execute against the author's own `WLM_ROOT`
(e.g. `~/authors/twain`); these directories are the *record*, refreshed via snapshot.

**What can never appear here:** private authors and research-use-only corpora (e.g. the Blog
Authorship Corpus blogger — its license permits use, not redistribution, and its authors are
real people). Two mechanical guards enforce this: `snapshot_author.py` refuses any root whose
RUNBOOK carries the PRIVATE AUTHOR marker, and `.gitignore` allow-lists authors one explicit
line at a time — there is no wildcard to inherit.

## twain

Mark Twain, conversational first-person American prose — *Chapters from My Autobiography*
(PG #19987) and *Mark Twain's Speeches* (PG #3188), 98 documents / ~151k words, extracted by
`scripts/build_author_corpus.py twain` (pinned, title-verified Gutenberg IDs; indented
third-person editorial notes stripped). Distractors: 340 windows from 17 era- and
register-matched American memoirists (registry and per-book IDs in the same script; Franklin,
Irving, Thoreau, Parkman and Dana are deliberately-flagged off-era entries). All US public
domain. `pairs.jsonl` generated by `claude-haiku-4-5` with the standard audit pass — note the
dev corpus's pairs were generated by `claude-sonnet-4-5`; the generator is recorded per pair
in the file and the difference is disclosed as a cross-author caveat (docs/EXPANSION.md).
