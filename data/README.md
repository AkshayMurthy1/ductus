# What in `data/` is committed, and why

`.gitignore` denies `data/**` and `runs/**` by default and re-includes specific paths. The rule is
**provenance first**: a path is committed only if it is redistributable *and* either expensive to
regenerate or a scientific record.

Run `make check-data` before any commit — it prints exactly what would be included and fails if
private writing is about to be committed.

## Committed

| Path | Size | Why |
|---|---|---|
| `data/raw/author/**` | ~1.7 MB | Public-domain author fixture. Reproducible via `scripts/build_dev_corpus.py`, but committing it pins the exact corpus a result was produced from. |
| `data/raw/distractor/**` | ~2.0 MB | Public-domain negative class. Same reasoning — the verifier's AUC is meaningless without knowing which negatives produced it. |
| `data/interim/pairs.jsonl` | ~3.4 MB | **~3,000 non-deterministic API calls.** Cannot be reproduced: same passages, same model, different questions. This is the only derived artifact worth its bytes. |
| `runs/**/report.json`, `report.html`, `run_meta.json` | ~1.9 MB | The record of each run — resolved config, metrics, trainable-parameter count, wall-clock. Tables are assembled from these. |
| `runs/**/gen.jsonl` | ~13 MB | Model generations. Reproducible only if you still have the adapter that produced them. |
| `runs/results/**`, `matrix_state.json`, `contamination.json` | ~50 KB | Assembled tables, frontier figure, matrix resume state. |

**Total ≈ 22 MB.** Under GitHub's limits with room to spare; no Git LFS required.

## Replication authors (`authors/<name>/`, repo root)

Each replication author is a complete in-repo experiment tree — `authors/<name>/{data,runs}` —
mirroring this root's layout and provenance rules (corpus + distractors + paid `pairs.jsonl` +
run records commit; deterministic intermediates and weights don't). One explicit `.gitignore`
allow-list block per author, never a wildcard: research-use-only corpora (the Blog Authorship
Corpus blogger) get no committable path, and private-author work lives in a separate
repository, not here (docs/STATUS.md §5). See `authors/README.md`.

## Not committed

**Weights and checkpoints** — `runs/` is ~14 GB on disk. Individual `adapter_model.safetensors`
files are ~118 MB, which is over GitHub's 100 MB hard per-file cap; 79 files exceed it. Publishing
adapters means release assets, Git LFS, or the HF Hub — not the repo. Each checkpoint also carries
its own 11 MB copy of the tokenizer, which is where most of the bulk actually comes from.

**Deterministic intermediates** — `docs.jsonl`, `chunks.jsonl`, `scrubbed.jsonl`, and everything
under `data/processed/` (including the sweep arms) are exact functions of the raw corpus plus a
seed. They regenerate byte-identically, so committing them stores nothing that isn't already
implied by `pairs.jsonl` and the config.

**`data/raw/_originals/`** — first-party private writing. Denied last in `.gitignore` so the rule
wins over every allow-list above it.

## Provenance and licensing

Everything currently committed under `data/raw/` is **US public domain**, sourced from Project
Gutenberg by `scripts/build_dev_corpus.py`:

- **Author:** G.K. Chesterton — five essay collections (*Heretics*, *Tremendous Trifles*,
  *All Things Considered*, *A Miscellany of Men*, *The Defendant*).
- **Distractors:** ~25 other essayists — Addison, Arnold, Belloc, Beerbohm, Benson, Birrell,
  Burroughs, Chapman, Emerson, Gissing, Hazlitt, Lamb, Le Gallienne, Lucas, Lynd, Mencken,
  Meynell, More, Pater, Quiller-Couch, Repplier, Stevenson, Thoreau, Twain, and others.
  Chesterton is asserted absent from this set by the build script.

`data/interim/pairs.jsonl` holds questions generated by `claude-sonnet-4-5` paired with
public-domain passages. The passages are public domain; the questions are machine-generated from
them.

> ⚠️ **If you swap the author fixture for private writing, this file's guarantees stop holding.**
> The allow-list keys on the *path* `data/raw/author/**`, not on what is in it. Before adding your
> own prose, either move the `data/raw/_originals/**` deny rule up to cover `data/raw/author/**`,
> or relocate the private corpus under any directory named `private/` — `.gitignore` already
> denies `data/raw/**/private/**` unconditionally.

Two corpora used earlier in this project are **not** currently present and are **not** freely
redistributable — check their terms before re-adding: **PERSUADE 2.0** (CC BY-NC-SA 4.0, so
non-commercial + ShareAlike + attribution) and **Cory Doctorow's *Content*** (CC BY-NC-SA).
